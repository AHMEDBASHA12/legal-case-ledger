دفتر القضايا والحسابات المالية — الإصدار 1.0

المحتويات
- index.html: التطبيق كاملًا.
- manifest.webmanifest و service-worker.js: التثبيت والعمل دون اتصال بعد أول فتح ناجح.
- icons/: أيقونات التطبيق.

الخصوصية والتخزين
- سجلات الموكلين والقضايا والحركات محفوظة في IndexedDB داخل المتصفح وعلى الجهاز نفسه.
- لا يوجد تسجيل دخول، ولا خادم قاعدة بيانات، ولا ترسل الحركات أو المرفقات إلى الإنترنت.
- ملفات التطبيق نفسها تُستضاف في GitHub Pages؛ لا تضع بيانات العملاء أو ملف النسخة الاحتياطية داخل مستودع GitHub.
- رابط GitHub Pages علني عادةً؛ الذي يُنشر هو كود التشغيل فقط، وليس قاعدة البيانات المحلية.
- احفظ نسخة JSON احتياطية بانتظام في مكان آمن خارج مجلد المشروع. افتح صفحة «النسخ» لاستعادتها على الجهاز نفسه أو جهاز آخر. البيانات لا تتزامن تلقائيًا بين iPhone وAndroid أو بين المتصفحات؛ يلزم التصدير والاستعادة لنقلها.
- بيانات المتصفح قد تُفقد عند مسح بيانات الموقع أو حذف المتصفح أو فقدان الهاتف. النسخة الاحتياطية ضرورية.
- افتح التطبيق عبر HTTPS؛ فتح index.html كملف مباشر لا يوفّر تجربة PWA مستقرة على كل الهواتف.

إطلاقه عبر GitHub Pages (مرة واحدة)
1. فكّ ضغط ملف المشروع على اللابتوب.
2. افتح مستودعك legal-case-ledger في GitHub.
3. اضغط Add file ثم Upload files.
4. ارفع كل المحتويات الموجودة داخل مجلد الإصدار، لا ترفع المجلد الخارجي نفسه فقط. يجب أن يظهر index.html في جذر المستودع.
5. اضغط Commit changes.
6. افتح Settings ثم Pages، اختر النشر من فرع main والمجلد /(root)، ثم Save.
7. انتظر حتى يظهر رابط Pages، افتحه من الهاتف.
8. iPhone: Safari > مشاركة > إضافة إلى الشاشة الرئيسية. Android: Chrome > القائمة > تثبيت التطبيق/إضافة إلى الشاشة الرئيسية.

اختبار أولي قبل بيانات حقيقية
- أنشئ موكلًا وهميًا ثم ملفًا.
- جرّب قبض 10,000 دون توزيع؛ يجب أن تظهر 10,000 «غير موزعة».
- جرّب قبض 10,000 وتوزيع 3,000 فقط؛ يجب أن تظهر 7,000 غير موزعة.
- جرّب دفع مصروف من مالك، ثم سجّل سدادًا جزئيًا من المقبوضات.
- جرّب PDF وWord وExcel، ثم صدّر نسخة JSON واستعدها على بيانات اختبار فقط. لا تبدأ بسجلات موكلين حقيقيين قبل التأكد من حفظ نسخة احتياطية واستعادتها بنجاح.

ملاحظة: لا تغيّر أسماء/مسارات الملفات بعد النشر دون التأكد من تحديث cache الخاص بالـ Service Worker. إذا حدّثت التطبيق ولم يظهر التحديث، أغلقه تمامًا وافتح الرابط مجددًا. لا تستخدم التصفح الخاص.
